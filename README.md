เพิ่มหรือแก้รายชื่อได้โดยตรงในแท็บ `Companies` ได้เลย

- PEA No. ต้องไม่ซ้ำกัน

## แก้ชื่อผู้ใช้ / รหัสผ่าน ใน Sheet

แท็บ `Users` แก้ได้โดยตรง มีผลภายใน 30 วินาที
- คอลัมน์ A `Username`: ชื่อที่ใช้ล็อกอิน
- คอลัมน์ F `รหัสผ่าน`: เก็บเป็นตัวอักษรธรรมดา พิมพ์ทับเพื่อเปลี่ยนรหัส (อย่างน้อย 6 ตัว)
- คอลัมน์ D `Active`: เอาติ๊กออกเพื่อปิดบัญชี

รหัสผ่านอยู่ใน Sheet แบบอ่านออกได้ จึงควรแชร์ Sheet เฉพาะผู้ดูแลระบบเท่านั้น
